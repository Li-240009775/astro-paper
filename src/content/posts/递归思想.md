### recursion结构与理解
一个递归函数要先确定base case作为函数出口，然后再考虑递归结构。引入调用栈可以更好理解递归（特别是八皇后那里的递归回溯），循环像是把所有的事情排成一列交给计算机一个一个做，而
递归就是让计算机自己找事做，在解决一个调用栈时又生成新的调用栈，最后全部解决全部return回来，整个调用栈先叠高再降低，（所以任何递归也可以用循环模拟调用栈来实现）有了这样的理解后，我们就能更好地设计递归代码。

### 汉诺塔直接找第k步
一开始我能理解一个n层汉诺塔应该分三步解决，但我完全理解不了怎么写代码可以跳过递归顺序把找第k步的时间复杂度降到O(n)，具体代码是这样的

```cpp
void k_move(int n,int k,char start,char tem,char desn){
    if (n <= 0) return;
    long long stage = (1LL << (n - 1)) - 1;     
    if (k <= stage)
        k_move(n - 1, k,start,desn,tem);
    else if (k == stage + 1)
        cout << start << ' ' << desn << '\n';
    else
        k_move(n - 1, k - stage - 1, tem, start, desn);
}
```       

现在就感觉很简单了，都不需要用调用栈辅助理解，把n层汉诺塔分成三步后，那个base case就是k==stage，如果不是，那我们面对的就是一个n-1的汉诺塔，再进行一次判断，只是改了起点和终点，也能理解
为什么有k-stage-1，因为这样它才是一个新的子汉诺塔，所以它不是跳过步骤，而是要解决的问题不一样了，需要的步骤本来就少，只要一直给汉诺塔降级并分情况直到k==stage。

### quicksort

quicksort的思路核心是给待处理数组分区，选一个pivot，按pivot分出大于区和小于区，然后递归处理两边，我一开始还想着每次都new一个tem数组出来，最后拼起来，但只要给函数输入要处理的区间直接修改原数组就行了。
base case则是数组长度为1或0，直接return
